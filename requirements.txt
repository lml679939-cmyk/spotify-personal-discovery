# ── 釘版策略：直接依賴一律精確釘死（==）──────────────────────────
#
# 為什麼不用 >= 浮動：
#   Streamlit Cloud 每次重新建置都會抓當下最新版，等於**部署的版本永遠不是你測過的
#   那一版**。實測踩到過：requirements 寫 `google-genai>=1.0`、本機裝的是 2.3.0，
#   而 PyPI 上已經是 2.19.0——正式站跑的 SDK 和本機差了 16 個 minor 版本。
#   浮動也代表上游任何一個問題版本會**自動上線**，你沒有審核的機會。
#
# 為什麼精確釘死不會變成「永遠不更新」：
#   `.github/dependabot.yml` 已設定每週檢查。⚠️ 但 Dependabot 對 `>=` 範圍幾乎不會動作
#   （範圍本來就允許新版，沒東西可 bump）——**改成 == 之後它才真正開始工作**，
#   每週開 PR 讓你審核後再合。
#
# 升級流程（尤其 streamlit）：
#   1. pip install --upgrade <套件>
#   2. python -m pytest -q                 ← 199 tests（數字會長，以 CLAUDE.md 為準）
#   3. streamlit run app.py，用瀏覽器量關鍵選擇器與間距
#      ⚠️ 本專案大量依賴 data-testid 與 .st-key-* class，升 streamlit 一定要重量一次
#         （驗收標準：所有垂直間距都要落在 8/16/24 三級制上，見 CLAUDE.md「版面幾何」）
#   4. 通過才更新這裡的版本號
#
# 以下版本組合已於 2026-08-20 完整驗證：tests 全過、登入頁與主表單選擇器齊全、
# 間距序列 24/8/16/8/16/24/16/16/16 全部在三級制上、訪客模式端到端生成成功。
# （IG 分享圖卡功能已於 2026-08-21 移除；Pillow 仍要釘版，理由見下。）
